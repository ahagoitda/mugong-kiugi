# 무공키우기 (Mugong Kiugi) - 모바일 방치형 RPG

**무공키우기**는 Phaser 3와 Capacitor를 기반으로 제작된 **무협 방치형 2D RPG 게임**입니다.  
이름 없는 무인이 되어 정파 사대문파의 잃어버린 비급을 습득하고, 중원을 침략한 마교인 혈교(血敎)의 50개 장(총 250웨이브)에 걸친 보스들을 물리치며 천하제일인으로 우뚝 서는 여정을 담고 있습니다.

---

## 1. 세계관 및 7단계 경지 (50장 스토리)

### 1.1 시놉시스
> 혈교가 중원을 침략하자 정파 사대문파(청운검문, 호풍도문, 비룡권문, 운령창문)는 궤멸 직전에 이르렀다.  
> 강호에 홀연히 나선 이름 없는 무인은 실종된 장문인들의 비급을 하나씩 이어받아 고무(古武)의 비전초식을 깨우친다.  
> 혈교의 50개 층위 보스를 쓰러뜨리며 자신의 경지를 끊임없이 고양하고, 마침내 강호의 화평을 실현해 나간다.

### 1.2 경지(境地)와 스테이지 구조 (총 50장)
게임은 7개의 대경지로 나뉘며, 각 경지마다 8개(생사경은 2개)의 장(Region)과 고유 보스가 등장합니다.

| 경지 | 장 범위 | 해금 웨이브 | 주요 보스 특징 | 보스 등급 명칭 |
|:---:|:---:|:---:|:---|:---|
| **초입 (Entry)** | 1장 ~ 8장 | 1 ~ 40 | 강호에 첫발을 내디딘 도적단 및 초급 혈교 자객 토벌 | 대주 (DAEJU) ~ 혈마 (HYEOLMA) |
| **일류 (First-Class)** | 9장 ~ 16장 | 41 ~ 80 | 정파 무사들과 마교 입문 제자들이 대치하는 격전지 | 일류 대주 ~ 일류 혈마 |
| **절정 (Climax)** | 17장 ~ 24장 | 81 ~ 120 | 음양의 조화와 기의 순환을 깨달은 절정 고수들과의 혈투 | 절정 대주 ~ 절정 혈마 |
| **초절정 (Super-Climax)** | 25장 ~ 32장 | 121 ~ 160 | 대자연의 힘을 다루며 공간을 뒤흔드는 초절정 마두 처단 | 초절정 대주 ~ 초절정 혈마 |
| **화경 (Transformed)** | 33장 ~ 40장 | 161 ~ 200 | 반로환동의 기틀을 닦고 원기를 마음대로 부리는 화경의 보스 | 화경 대주 ~ 화경 혈마 |
| **현경 (Mystic)** | 41장 ~ 48장 | 201 ~ 240 | 검을 쓰지 않고도 기공만으로 상대를 제압하는 현경의 절대자 | 현경 대주 ~ 현경 혈마 |
| **생사경 (Life & Death)** | 49장 ~ 50장 | 241 ~ 250 | 삶과 죽음의 경계를 넘나드는 반인반신의 교주와 혈마강세 | 생사 대주 ~ 무령 혈마 |

## 2. 모바일 풀스크린 및 하이브리드 엔진 아키텍처

본 프로젝트는 모바일 기기에서의 시각적 만족도를 극대화하고 다양한 디스플레이 종횡비에 자연스럽게 대응하기 위해 **동적 높이 뷰포트 레이아웃**을 채택하고 있습니다.

```
┌─────────────────────────────┐  ─┐
│        [상단 영역]          │   │
│  횡스크롤 전투 (BattleScene)  │   │ 기기 비율에 따라
│   캐릭터 자동 전투 및 대시  │   │ 세로 높이가 동적 확장
│                             │   │ (Open viewport)
├─────────────────────────────┤  ─┘
│        [하단 영역]          │  ─┐
│     UI 패널 (UIScene)       │   │ 340px 고정 점유
│  무공 합성, 장비, 임무 탭   │   │ (Bottom docking)
└─────────────────────────────┘  ─┘
```

- **동적 세로 해상도 계산 (`src/main.ts`)**:  
  기기의 가로 폭을 `540`으로 고정(Viewport Scale)한 뒤 기기 높이비(`window.innerHeight / window.innerWidth`)를 곱해 `BASE_H`를 실시간 계산합니다. 노치(Notch) 및 펀치홀 카메라 영역에 맞게 브라우저의 `safe-area-inset` 패딩을 결합합니다.
- **반응형 뷰포트 분할**:
  - `BattleScene`은 `scale.height - 340`으로 뷰포트 높이(`battleH`)를 산출하여 상단을 장식합니다. 기기가 길어질수록 웅장한 패럴랙스 배경과 하늘이 더 넓게 렌더링됩니다.
  - `UIScene`은 하단 네비게이션과 무공 관리 독(Dock)의 Y축 좌표들을 `H - 35`, `H - 154`, `H - 318` 등 상대 좌표로 배치하여 기종 구분 없이 완벽하게 바닥면에 밀착시킵니다.

## 3. 고품질 크로마키 자산 및 가공 파이프라인

레트로 픽셀 도트 스타일의 투박함을 버리고, **고화질 2D Cell-Shaded** 풍의 무협 자산을 런타임에 즉시 활용하기 위해 자동화 가공 파이프라인이 내장되어 있습니다.

### 3.1 크로마키(그린/블랙 스크린) 투명화 스크립트
1. AI 생성 및 원본 이미지를 `public/sprites/originals/` 에 저장합니다. (예: 녹색 배경 `#00FF00` 혹은 카드 테두리의 검은색 배경)
2. `node scripts/process-assets.js` 를 실행하면 이미지 프로세서 `Sharp`가 다음 연산을 실행합니다:
   - **그린스크린 제거**: $G$ 채널이 우세한 픽셀의 Alpha 값을 투명(0) 처리하고, 경계면의 녹색 후광(Green Spill)을 채도 감소(Desaturation) 기법으로 보정하여 깔끔하게 다듬어 냅니다.
   - **블랙스크린 제거**: $Max(R,G,B)$ 가 어두운 임계값 이하인 영역을 투명 알파 처리하여 UI 프레임 카드를 선별합니다.
   - **출력 최적화**: 압축 효율이 높은 `.webp`와 고선명 투명 알파를 보존하는 `.png`로 변환 배포합니다.
3. 런타임 최종 자산은 `public/sprites/generated/runtime/` 경로에 자동 적재됩니다.

## 4. 안드로이드 모바일 출시 및 빌드 가이드

Capacitor CLI와 Gradle 컴파일러를 활용하여 완성된 웹앱 코드를 안드로이드 패키지(APK) 파일로 빌드하는 가이드입니다.

### 4.1 필수 사전 개발 환경
- **Node.js**: v18 이상
- **Android Studio**: 최신 버전 (Android SDK 34 이상 포함)
- **Java Development Kit (JDK)**: JDK 17 설치 및 `JAVA_HOME` 환경 변수 등록 완료 상태

### 4.2 빌드 및 안드로이드 프로젝트 동기화
1. **의존성 설치**
   ```bash
   npm install
   ```
2. **웹 배포용 빌드 컴파일**
   ```bash
   npm run build
   ```
3. **Capacitor 빌드 동기화 (dist 배포 파일을 android/assets로 이관)**
   ```bash
   npm run android:sync
   ```

### 4.3 안드로이드 스튜디오에서 앱 기동 및 디버깅
1. **안드로이드 프로젝트 실행**
   ```bash
   npm run android:open
   ```
2. Android Studio가 열리면 기기를 USB로 연결하거나 virtual emulator(AVD)를 실행한 뒤, 상단의 **Run 'app'** (초록색 재생 아이콘)을 눌러 설치 및 실행합니다.

### 4.4 배포용 APK / AAB 빌드
1. **디버그용 APK 생성 (터미널 명령)**
   ```bash
   cd android
   ./gradlew assembleDebug
   ```
   - 출력물 경로: `android/app/build/outputs/apk/debug/app-debug.apk`
2. **구글 플레이 스토어 업로드용 AAB 생성**
   - Android Studio 메뉴: `Build` -> `Generate Signed Bundle / APK` -> `Android App Bundle` 선택 후 키스토어 서명을 거쳐 릴리즈용 `.aab` 파일을 생성합니다.

## 5. 프로젝트 주요 디렉터리 구성

```
mugong-kiugi/
├── android/                         # Capacitor가 생성한 안드로이드 스튜디오 네이티브 프로젝트
├── docs/
│   └── contents_plan.md             # 마스터 기획서 (경지명, 수련 계열, 장비 수식어)
├── scripts/
│   ├── process-assets.js            # Sharp 엔진 크로마키(그린/블랙) 제거 및 WebP 변환
│   └── generate-hero-prompts.py     # Grok Builder 스프라이트 생성용 프롬프트 생성 헬퍼
├── public/
│   └── sprites/
│       ├── originals/               # AI 생성 원본 크로마키 리소스 보관
│       └── generated/runtime/       # 인게임 최종 로딩 투명 알파 웹 배포 경로
└── src/
    ├── main.ts                      # 게임 환경 설정 및 세로 풀스크린 높이 동적 연산
    ├── data/
    │   ├── enemies.ts               # 50장 보스 및 경지(Realm) 정보 자동 생성 데이터
    │   └── skills.ts                # 무공 비급 DB 및 합성 조합 표
    └── scenes/
        ├── BattleScene.ts           # 상단 동적 뷰포트 기반 자동전투 및 3단 패럴랙스 배경
        └── UIScene.ts               # 하단 3대 고정 독(Dock) 및 경지 탭 보스 일람 구현
```
