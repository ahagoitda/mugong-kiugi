# 무공키우기 (Martial Arts Idle Action) - MVP 기획서

## 1. 게임 개요
- **장르**: 2D 도트 액션 + 방치형(Idle) RPG
- **플랫폼**: Android (오프라인 전용)
- **핵심 루프**: 전투(자동/수동) → 비급 획득 → 비급 합성(상위 무공 해금) → 장착 및 전투 효율 상승
- **기술 스택**: Phaser 3 (WebGL 렌더러) + TypeScript + Capacitor

## 2. 핵심 시스템

### 2.1. 전투 시스템 (상태머신 기반)
캐릭터는 장착한 무공에 따라 공격 패턴(애니메이션, 히트박스, 사거리, 이펙트)이 완전히 달라집니다.

- **자동 전투 (Auto Battle)**
  - AI가 적과의 거리를 계산하여 장착된 무공 중 최적의 무공을 쿨타임 우선순위로 사용합니다.
  - 로테이션 예시: 돌진기(거리 좁히기) → 연타기(딜링) → 광역기(다수 제어)
- **수동 전투 (Manual Battle)**
  - 플레이어가 직접 이동, 회피(대시), 무공 버튼을 조작합니다.
  - 무공 시전 중 캔슬, 무적 프레임(회피) 활용 등 컨트롤 요소가 존재합니다.

### 2.2. 비급 합성 시스템 (성장)
단순히 수치만 오르는 강화가 아니라, **새로운 모션과 판정을 가진 상위 무공**으로 진화합니다.

- **합성 공식**: 동일한 하위 비급 2개 합성 → 상위 비급 1개 획득 (확률 또는 확정)
- **장착 슬롯**: 액티브 무공 3개, 패시브(내공/보법) 1개 장착 가능

## 3. 무공 데이터 구조 (MVP 기준)

MVP 단계에서는 가장 직관적인 **검법(劍法)** 1개 계열만 우선 구현하여 전투 루프를 검증합니다.

| 등급 | 무공명 | 기술적 특징 (모션 & 판정) | 게임 내 효과 |
|---|---|---|---|
| **하급** | 삼재검법 (三宰劍法) | 3프레임 모션, 전방 좁은 범위 베기 | 기본 콤보, 짧은 쿨타임 |
| **하급** | 육합검 (六合劍) | 5프레임 모션, 전후방 동시 타격 | 다수 적 견제, 방어적 스탠스 |
| **중급** | 매화검법 (梅花劍法) | 12프레임 모션, 전방 부채꼴 다단 히트 | 파티클 이펙트(매화), 높은 누적 딜 |
| **중급** | 청풍검법 (淸風劍法) | 8프레임 모션, 빠른 찌르기 후 뒤로 회피 | 치명타 특화, 치고 빠지기 |
| **상급** | 태극검법 (太極劍法) | 20프레임 모션, 제자리 회전 후 검기 발사 | 적 투사체 패링, 원거리 검기 |
| **최상급** | 창궁무애검법 (蒼穹無涯) | 30프레임 모션, 화면 절반을 덮는 거대 검강 | 화면 내 적 전체 압도적 물리 대미지 |

### 3.1. 보법/신법 (회피기)
- **초상비 (草上飛)**: 기본 대시. 짧은 무적 프레임 제공.

## 4. 데이터 모델 (TypeScript Interface)

```typescript
// 무공 데이터 구조
interface SkillData {
  id: string;
  name: string;
  grade: 'LOW' | 'MID' | 'HIGH' | 'ULTIMATE';
  type: 'ACTIVE' | 'PASSIVE' | 'DASH';
  range: number;        // 사거리 (픽셀)
  cooldown: number;     // 쿨타임 (ms)
  damageMultiplier: number; // 대미지 배율
  
  // 애니메이션 및 판정 데이터
  animKey: string;
  totalFrames: number;
  hitFrames: number[];  // 타격 판정이 발생하는 프레임 인덱스 배열
  moveOffset: { x: number, y: number }; // 시전 중 캐릭터 이동량 (돌진기 등)
  
  // 부가 효과
  effects?: 'STUN' | 'BLEED' | 'KNOCKBACK';
}

// 캐릭터 상태머신
type CharacterState = 'IDLE' | 'RUN' | 'ATTACK' | 'DASH' | 'HIT' | 'DEAD';
```

## 5. UI/UX 플로우
1. **메인 화면 (HUD)**: 상단(체력/내공 바), 하단(장착된 무공 슬롯 3개 + 대시 버튼), 중앙(전투 화면)
2. **도감/합성 팝업**: 획득한 비급 목록 표시. 드래그 앤 드롭 또는 버튼 클릭으로 합성 진행.
3. **장착 팝업**: 해금된 무공을 하단 슬롯에 할당.

## 6. 개발 페이즈 (MVP)
1. **엔진 세팅**: Phaser 3 캔버스 렌더링, Arcade Physics 적용
2. **기본 전투**: 플레이어 이동, 적 추적, 기본 공격(삼재검법) 히트박스 판정
3. **무공 확장**: 매화검법(다단히트), 창궁무애검법(검기) 추가 및 상태머신 연동
4. **시스템 연동**: 적 처치 시 비급 드랍 → 인벤토리 → 합성 → 장착 루프 완성
5. **최적화**: 오브젝트 풀링(적, 이펙트) 적용 및 모바일 60fps 확인
