# 전투 시스템 · 진행 곡선 분석 (2026-06)

코드의 실제 수식을 그대로 옮긴 시뮬레이터(`scripts/simulate-progression.mjs`,
`node scripts/simulate-progression.mjs`로 재현 가능) 기반 분석.

---

## 1. 시스템 맵

### 전투 파이프라인
```
[자동 AI] 사거리 내 가장 강한 스킬부터 시전 (BattleScene.updateBattleAI)
   ↓
[플레이어 데미지] (스킬배율×10 + 장비공격) × 직업배율 × 레벨보너스 × 강화보너스 × 공격배율 × 치명타
   레벨보너스 = 1 + (lv-1)×0.05        강화보너스 = 1 + 스킬lv×0.08
   공격배율 = 세트 × (1 + 수련×0.02 + 연구×0.025 + 제자×0.01)
   ↓
[적 → 플레이어] 회피( min(70%, 18% + (lv-1)×2.5%) ) → 피해 = dmg/체력배율 − 장비HP×0.015
   + 패시브 재생 maxHp×0.4%/s, 기력 3/s
```

### 성장 축 (7개)
| 축 | 효과 | 상한 | 비용 곡선 |
|---|---|---|---|
| 레벨 | 공격 +5%/lv, 회피 +2.5%/lv | 회피는 lv22에 70% 캡 | exp = 50+(lv-1)×30+lv^1.5×10 |
| 무공 등급 | 배율 1.0 → 1.6 → 3.0 → 5.0 | ULT | 합성 50/50/200/1000G + 드랍 |
| 무공 강화 | +8%/lv | LOW 20 ~ ULT 40 | base×(1+lv×0.32), 재료 2개 |
| 수련 | 공격/체력/금화 +2%/lv 등 6종 | 공격 20lv(+40%) | 100×(lv+1) |
| 문파 | 연구 +2.5%/lv, 제자 +1% | — | 연구 220×(lv+1), 제자 600+n×350 |
| 장비 | flat 공격/HP + 세트(2/4/6: 공+8%/HP+12%/공+12%·금+18%) | region 비례 | 드랍 22%/보스 100% |
| 환생 | 오프라인 보상 ×(1+0.15n) | — | **실행 로직 미구현 (아래 이슈 #1)** |

### 적 스케일 (난이도 전역 배율: 졸병 HP×0.45 DMG×0.12 / 보스 HP×0.38 DMG×0.14)
- 졸병: HP=(28+n×8)×(1+(w-1)×0.015), n은 **8개 region 순환**으로 결정
- 보스: HP=260+(s-1)×450+(s-1)²×20, 5웨이브마다, **wave 50 이후 40웨이브 사이클당 HP×+0.8/DMG×+0.5**

## 3. 발견된 설계 이슈

1. **환생 시스템 미구현 (죽은 기능)** — `rebirthCount`/`rebirthPaths` 저장 필드와
   오프라인 보상 배율(×1+0.15n)만 존재하고, 환생을 실행하는 UI/로직이 어디에도 없음.
   장기 리텐션의 핵심 루프가 비어 있는 상태.
2. **wave 90 사이클 단차** — 50웨이브 이후 보스만 HP ×1.8 점프하고 졸병은 그대로.
   적극 성장 유저도 wave 90에서 TTD(8s) < TTK(18s)로 막힘. 성장 축은 이 시점에
   수련 캡(70w 부근 도달)·회피 캡(lv22)이 끝나 있어 돌파 수단이 강화/장비뿐.
3. **졸병 무위협 + 톱니 난이도** — DMG 전역 배율 0.12가 너무 낮고 region 순환으로
   강함이 리셋됨. 긴장감·회피기 사용 동기가 없음.
4. **회피 스탯의 조기 캡** — lv22에 70% 도달 후 생존 성장이 멈춤. 후반 벽(이슈 2)과
   직결.
5. **수련/연구의 이른 캡** — 공격 수련 20lv(+40%)이 wave ~70이면 끝.
   골드 수입은 계속 늘어나는데(보스 120+200s) 소비처가 강화 하나로 수렴.
6. **레거시 데이터 필드** — `skill.animKey`는 어떤 코드도 소비하지 않음 (모션은
   attackMotion/heroic 시퀀스로 대체됨). 혼동 방지를 위해 제거 후보.
7. **보스 스킬의 회피 불가능성** — projectiles/rain은 플레이어 좌표로 유도되어
   위치 회피가 불가하고, 무적 회피(경공)만 유효. AUTO 모드는 HP<35%에서만
   경공을 쓰므로 사실상 확률 회피(18~70%)에만 의존.
